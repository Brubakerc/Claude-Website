# How to add 3D models

The 3D viewer shows `.glb` files. GLB is a compact file format for 3D models on the
web, the way JPEG is for photos. CAD programs export STL or STEP; this page turns
those into a small GLB.

## Easiest: export GLB directly

Some CAD tools save GLB (or glTF, the same thing in several files) themselves:

- **Onshape:** right-click the part or assembly, **Export**, format **GLTF**, and tick
  "Download as binary" if offered (that's GLB).
- **Fusion:** **File → Export**, type **GLB** (or OBJ, then convert below).
- **Blender:** **File → Export → glTF 2.0**, format **glTF Binary (.glb)**.

If that works, skip to "Putting it on a page".

## From STL or STEP: use the script

`scripts/convert_to_glb.py` converts STL, OBJ, PLY, 3MF, or STEP files.

**One-time setup.** You need Python 3.9 or newer. Python is a programming language;
the script runs in it. On a Mac or Windows PC, open a terminal (Terminal on Mac,
PowerShell on Windows) and run:

```
pip install trimesh numpy
```

For STEP files also run `pip install cascadio`. (Or export STL from your CAD program
and skip this.)

**Convert a file.** Download this repository to your computer (green **Code** button
→ **Download ZIP**, then unzip), open a terminal in that folder, and run:

```
python3 scripts/convert_to_glb.py path/to/bracket.stl
```

It writes `bracket.glb` next to the original and prints the size. Options:

| Option | Meaning | Example |
|---|---|---|
| `--out` | Where to save it | `--out src/content/projects/rover/bracket.glb` |
| `--units` | Units of the CAD file: `mm` (default), `cm`, `m`, `in` | `--units in` |
| `--max-faces` | Simplify detailed meshes to this many triangles (default 150,000) | `--max-faces 60000` |
| `--color` | Color as red,green,blue from 0 to 1 (default aluminum) | `--color 0.2,0.35,0.6` for blue anodize |
| `--roughness` | 0 is mirror-shiny, 1 is matte (default 0.35) | `--roughness 0.6` |
| `--metallic` | 1 for metal, 0 for plastic (default 1) | `--metallic 0` for a printed part |

**Keep it small.** Aim for under 5 MB; under 2 MB loads quickly on a phone. If the
file is too big, lower `--max-faces`. For STL exports, choosing a coarser
"resolution" or "deviation" setting in your CAD program also helps.

## Putting it on a page

1. Upload the `.glb` file into the project's folder, next to `index.mdx`.
2. Add it to the project in one of two ways.

   In the text, where you want it:

   ```mdx
   <Model3D file="./bracket.glb" title="Bracket, Rev B" caption="6061-T6, 3 mm sheet." />
   ```

   Or in the frontmatter, to show it at the end of the page:

   ```yaml
   models:
     - file: ./bracket.glb
       title: "Bracket, Rev B"
       caption: "6061-T6, 3 mm sheet."
   ```

Visitors can drag to rotate and pinch or scroll to zoom. While it loads, and on
devices that can't show 3D, the project's cover image is shown instead. The viewer's
code only loads on pages that have a model, so other pages stay fast.
