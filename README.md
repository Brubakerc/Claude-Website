# Portfolio website template

A portfolio site for engineering projects, built with [Astro](https://astro.build)
and published with GitHub Pages. Everything here is placeholder content
("Your Name", "Sample: …") waiting to be replaced.

Start with `MORNING_REPORT.md`. Then:

| To… | Read |
|---|---|
| Put the site online | `docs/HOW_TO_PUBLISH.md` |
| Add a project | `docs/HOW_TO_ADD_A_PROJECT.md` |
| Change your name, links, style, colors, fonts | `docs/HOW_TO_CUSTOMIZE.md` |
| Add 3D models from STL or STEP | `docs/HOW_TO_ADD_3D_MODELS.md` |
| See how the four styles were designed | `docs/STYLES.md` |

Site settings: `src/site.config.ts`. Projects: `src/content/projects/`.

To work on it on your own computer (optional): install Node.js 20 or newer, then run
`npm install` and `npm run dev` and open the address it prints.
